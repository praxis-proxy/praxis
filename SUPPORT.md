# Getting Help

## Questions & Discussions

Usage questions, configuration help, and general discussion belong in one
of these channels:

| Channel | Link |
| --- | --- |
| GitHub Discussions | <https://github.com/praxis-proxy/praxis/discussions> |
| CNCF Slack | [#praxis on CNCF Slack](https://cloud-native.slack.com/archives/C0BK0RSP5RC) ([join here](https://slack.cncf.io)) |

Please **do not** open an issue for questions. Issues are for actionable bug
reports and feature requests.

## Bug Reports

Found a bug? Open an issue using the
[Bug Report](https://github.com/praxis-proxy/praxis/issues/new?template=bug-report.yml)
template. Include steps to reproduce, the Praxis version, and any relevant
configuration.

## Security Vulnerabilities

**Do not open a public issue for security vulnerabilities.**

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/praxis-proxy/praxis/security/advisories/new).
See [SECURITY.md](SECURITY.md) for full details on our security policy,
severity classification, and response timeline.

## Feature Requests

Feature ideas start as an
[Enhancement](https://github.com/praxis-proxy/praxis/issues/new?template=enhancement.yml)
issue. Larger proposals that span multiple PRs go through the
[proposal process](https://github.com/praxis-proxy/enhancements).
