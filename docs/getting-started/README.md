# Getting Started

Start here to run Praxis for the first time. Read the pages in this order:

1. [Quickstart](quickstart.md): run the published container image as a
   reverse proxy in front of a backend, send a request, and clean up.
2. [Build from source](build-from-source.md): build the `praxis` binary from
   a checkout and run the same kind of proxy locally, plus the built-in
   default responder and the `cargo xtask` test servers.

Then continue with [configuration](../operating/configuration.md) and
[security hardening](../operating/security-hardening.md) before you deploy.
To proxy model APIs or agent protocols, use the
[Praxis AI quickstart](https://github.com/praxis-proxy/ai/blob/main/docs/quickstart.md).
