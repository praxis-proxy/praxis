# Getting Started

Read these pages in order:

1. [Quickstart](quickstart.md): run the published container image in front
   of a backend, send a request, and clean up.
2. [Route requests](route-requests.md): send two paths to two backends
   through one listener.
3. [Build from source](build-from-source.md): build the `praxis` binary and
   run a local proxy, the built-in default responder, and the `cargo xtask`
   test servers.

Before you deploy, read [configuration](../operating/configuration.md) and
[security hardening](../operating/security-hardening.md). To proxy model APIs
or agent protocols, use the
[Praxis AI quickstart](https://github.com/praxis-proxy/ai/blob/main/docs/getting-started/quickstart.md).
